# 1. 背景

用户刷 X 时间线时帖子多、单条阅读和构思评论耗时。希望在网页端用浏览器插件辅助：理解当前帖子，生成若干条可选用评论，选中后写入回复框，由用户自己发送。模型调用使用用户自备的 API Key（BYOK）。

## 2. 目标

- 缩短「看帖 → 想评论 → 填入回复框」的时间。
- 评论必须由用户点选后才写入，插件不自动发送。
- Key、模型和提示词配置保存在本地，不经过第三方中转。

非目标：

- 不自动发帖、不自动批量评论。
- 不抓私信、不操作其他账号。
- 不做多账号切换、不做定时任务。

## 3. 用户与场景

主要用户：自己刷时间线、希望更快完成点赞和回复的个人用户。

主场景：

1. 打开 x.com 首页或关注时间线。
2. 看到一条想互动的帖子。
3. 点击插件入口，得到几组评论候选。
4. 选一条，评论写入回复输入框。
5. 用户自行修改并发送，或放弃。
6. 需要时一键点赞。

## 4. 范围

首版只覆盖网页端时间线中的单条帖子回复。

包含：

- Chrome / Edge 扩展，Manifest V3。
- 时间线帖子识别与正文提取。
- 按需生成评论候选。
- 候选列表展示、选择、写入回复框。
- 当前帖子点赞。
- 选项页：供应商、API Key、模型、人设/提示词。

不包含：

- 引用转发、长帖分段编辑、图片理解。
- 自动对视口内全部帖子预生成。
- Firefox 首版适配。

## 5. 功能需求

### 5.1 帖子识别

- 在 `https://x.com/*` 和 `https://twitter.com/*` 注入。
- 识别时间线中的帖子卡片，至少提取：作者名、handle、正文、是否含图片/视频/链接的标记。
- 时间线滚动加载新帖子后，新帖子也能出现入口。
- 引用帖、转帖优先使用当前卡片可见正文；引用原文作为可选上下文，首版可只传主正文。

### 5.2 生成入口

- 每条帖子操作栏增加「AI」按钮。
- 点击后针对该帖请求评论，不在页面加载时自动打模型。
- 同一帖子重复点击可重新生成。
- 生成中按钮或面板显示加载状态，失败时展示错误原因。

### 5.3 评论候选

- 默认返回 4 条。
- 风格固定为四类：认同、补充、轻提问、短评。
- 每条默认不超过 80 个字。
- 语言默认跟随帖子；帖子为中文则中文，英文则英文。可在选项里强制指定语言。
- 不生成话题标签堆砌，不假装认识作者。

### 5.4 选择与写入

- 候选以浮层列表展示在入口附近。
- 点击某一条后：
  1. 打开该帖回复框。
  2. 将文本写入输入框。
  3. 关闭浮层。
- 不自动点击发送。
- 若回复框已有内容，默认追加到末尾；选项可改为覆盖。
- 写入失败时保留候选浮层，并提示失败。

### 5.5 点赞

- 插件入口旁提供点赞按钮，或在候选浮层提供「点赞」。
- 点击等价于触发该帖现有点赞控件。
- 已点赞则不再重复点，按钮状态反映当前是否已赞。
- 点赞与评论互不绑定。

### 5.6 BYOK 与配置

选项页字段：

- 供应商：OpenAI、xAI、Anthropic。
- API Key：密码框，只存 `chrome.storage.local`。
- 模型名。
- 人设补充：可选，拼进系统提示词。
- 评论语言：跟随帖子 / 固定中文 / 固定英文。
- 候选条数：3 到 5。
- 写入方式：追加 / 覆盖。

校验：

- 未配置 Key 时，点击生成直接提示去选项页，不发请求。
- Key 不出现在页面 DOM、不写日志。

### 5.7 模型请求

- 请求由扩展后台发出，内容脚本不持有 Key。
- 输入为帖子正文，截断到约 1200 字。
- 输出必须是 JSON 字符串数组，解析失败视为生成失败。
- 单次请求超时 30 秒。
- 供应商返回错误时，展示原始错误信息的简短版本。

## 6. 交互

- 浮层不遮挡整页，点击空白处关闭。
- 切换到另一条帖子的「AI」时，关闭上一个浮层。
- 暗色模式下浮层对比度可读。
- 入口按钮不影响原有回复、转帖、点赞点击区域。

## 7. 数据与隐私

- 本地保存：供应商、Key、模型、人设、语言、条数、写入方式。
- 发往模型的数据仅限当前帖子可见文本和用户配置的人设。
- 不上传浏览历史，不做远端账号。
- 卸载扩展后，本地存储由浏览器清除。

## 8. 异常

- 找不到帖子正文：提示无法提取。
- 回复框超时未出现：提示写入失败，候选仍可复制。
- 页面结构变化导致入口找不到：选项页提供「选择器失效」说明，代码中选择器集中配置。
- 网络或 401/429：提示检查 Key、额度或稍后重试。

## 9. 验收

- 配置 Key 后，时间线帖子可出现 AI 入口。
- 点击后 30 秒内得到 4 条候选，或明确失败原因。
- 点选候选后，文本出现在该帖回复框，且未发送。
- 点赞按钮能切换当前帖点赞状态。
- 清空 Key 后无法生成，并提示配置。
- 滚动加载的新帖子同样有入口。

## 10. 约束与风险

- X 页面结构经常变，选择器和写入方式需要可替换。
- 自动发送、批量评论更容易触发平台风控；首版明确不做。
- 用户需自行遵守 X 的使用条款和模型供应商条款。
